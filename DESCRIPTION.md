# Anima

The machinery of thinking souls.

> From Latin _anima_ - "soul, vital principle, breath"

Anima is a library mod, used by [Autarkia](https://modrinth.com/project/autarkia) and [Fidelia](https://modrinth.com/project/fidelia). It provides a framework for any kind of autonomous _agent_, with helpers and registries for advanced navigation/parkour, POI memory, relationships, perception, social contact, and more. It has a lot of built-in debugging tools: journalling, shared command surface, per-agent and per-species configuration (Aspects) and various in-world debug views.

This mod was initially developed as part of Autarkia, but it was split to be able to use independently of it, and to allow other developers to use and improve this base. This mod has no knowledge of what specifically it is driving. The rule of thumb about what to add here instead of inside Autarkia /Fidelia is: if it makes sense on both a Person and a Dog/Wolf, it makes sense here. Navigation, Perception, Social: Anima. The actual things to be percepted, how exactly are the walk capabilities and exact paths: derived mod.

## What this mod provides

| Feature        | Details                                                                                                                                              |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Brain**      | Arbiter over layered strategies. Instincts and HTN task planning, state machine for each task                                                        |
| **Navigation** | Nav grid, A*, gaits, parkour and the Navigator state machine                                                                                         |
| **Perception** | POI memory, near and horizon scanning, detection of other entities and their intent/actions                                                          |
| **Identity**   | `AgentId`, public/private identity tiers, `AgentDirectory` that outlives the body                                                                    |
| **Social**     | "Contact book" where each agent keeps track of its own relationships, per-player client sync that updates the UI according to each player's contacts |
| **Needs**      | RimWorld-similar declared needs, with thresholds, decay, limits, levels. Trackable to each reason                                                    |
| **Journal**    | Per-agent and per-"organ" logging for easy debugging, and a death black box                                                                          |
| **OP tools**   | Extended command surface designed to be extended by each mod, in-world debug visualizations, admin wand to order agents manually                     |
| **Config**     | Knobs registered per-mod and per-species, dynamic TOML files, per-world overrides                                                                    |

## Versions and compatibility

**Fabric**, for Minecraft **1.21.11**, **26.1.x** and **26.2.x**. Needs **Fabric API**.

First-party support for **Forge / NeoForge** through [Sinytra Connector](https://connector.sinytra.org/). All features in this mod are 100% compatible with it. I don't want to lock this mod to a single loader, but also don't have to build 2 compat layers. May change my mind in the future and actually build a Forge/NeoForge compat layer.

For now, this isn't expanded to 1.20.1 and 1.21.1, because Anima's Person entity is (currently) limited by being dependent on the 1.21.9+ Avatar entity and other limitations. As most of my effort is redirected towards that mod, I won't directly support those versions for now. _Maybe with Fidelia being released?_

Anima is published as its own download and is never bundled inside the mods that use it. Add it as a dependency and let the user download the latest version from Modrinth. All mods should use the same version, to avoid incompatibility.
